# Архитектура и запуск

Техническая документация сайта рынка «Южный». Короткое описание проекта лежит в [README](../README.md).

## Устройство

Статический сайт без сборки и без фреймворков. Файлы отдаются хостингом как есть.

| Путь | Что это |
|---|---|
| `index.html` | главная: категории, блок «Стиль на Южном», 3D-схема рынка, контакты и карта |
| `kategorii.html` | все 13 категорий товаров рынка |
| `magazin.html` | магазин одежды: каталог с фильтрами, окно товара, фото-тур «Как нас найти» |
| `404.html` | страница «не найдено», закрыта от индексации (`noindex`) |
| `assets/css/style.css` | базовые стили и компоненты |
| `assets/css/mh.css` | основной слой дизайна и все поздние правки (шапка, схема, кнопка MAX, адаптив) |
| `assets/css/fonts.css` | локальные шрифты Nunito Sans и Oswald (`assets/fonts/`, 8 файлов woff2) |
| `assets/js/app.js` | общая логика: ссылки MAX, каталог (массив `PRODUCTS`), схема рынка, меню, ленивая карта |
| `assets/js/mh.js` | шапка, активный пункт меню, карусель категорий, переходы между страницами |
| `assets/js/product.js` | окно товара: на компьютере по центру, на телефоне шторка снизу с жестами |
| `tools/set-domain.js` | подставляет домен во все места, где он нужен поисковикам |
| `.htaccess` | https, адрес без www, сжатие, кэш, закрытые служебные папки (Apache) |
| `_parts/` | старые фрагменты разметки, сейчас никуда не подключены |

Шапка и подвал продублированы в каждой из четырёх страниц. Правку в них нужно повторять во всех файлах.

## Перед запуском

1. **Ссылка на MAX.** В `assets/js/app.js` в строке `const MAX_URL = 'https://max.ru/';` впишите ссылку на профиль или чат рынка.
   Где взять: MAX → Профиль → QR-код → «Скопировать ссылку» (вид `https://max.ru/u/xxxxxxxx`).
   Все кнопки «Написать в MAX» берут ссылку отсюда.
   MAX не подставляет текст сообщения по ссылке, поэтому при нажатии текст («Хочу примерить: …») копируется в буфер и появляется подсказка. Копирование работает только по https.
   В настройках приватности MAX незнакомым людям должно быть разрешено писать.

2. **Домен.** Когда домен куплен, в папке сайта:
   ```
   node tools/set-domain.js https://рынок-южный-рт.рф
   ```
   Скрипт пропишет адрес в `canonical`, Open Graph, микроразметке, `sitemap.xml` и `robots.txt`. Кириллический домен он сам переводит в punycode. Сейчас там заглушка `https://example.com`, с ней сайт в поиск не отправлять. При смене домена команду можно запускать повторно.

3. **SSL-сертификат.** Включить Let's Encrypt в панели хостинга до загрузки `.htaccess`: файл перенаправляет все адреса на https.

## Что загружать на хостинг

Всё, кроме `_parts/`, `tools/`, `docs/`, `README.md`, `.git/`. Если они попадут на сервер, ничего страшного: служебные папки закрыты в `robots.txt` и `.htaccess`.

Сайт не использует эти картинки, их можно не загружать: `assets/img/decor/` (1,5 МБ), `assets/img/scheme.jpg`, `assets/img/plan.jpg`, `assets/img/store/*-new.jpg`, `assets/img/store/jeans-straight-back.jpg`.

### Хостинг на nginx (VPS)

```nginx
server {
    listen 80;
    server_name ваш-домен.ru www.ваш-домен.ru;
    return 301 https://ваш-домен.ru$request_uri;
}
server {
    listen 443 ssl http2;
    server_name www.ваш-домен.ru;
    # ssl_certificate ...;
    return 301 https://ваш-домен.ru$request_uri;
}
server {
    listen 443 ssl http2;
    server_name ваш-домен.ru;
    # ssl_certificate ...;
    root /var/www/yuzhny;
    index index.html;
    error_page 404 /404.html;
    location = /index.html { if ($request_uri ~ ^/index\.html) { return 301 /; } }
    location ~ ^/(_parts|tools|docs)/ { return 404; }
    location ~* \.(jpg|png|svg|ico|woff2)$ { expires 180d; add_header Cache-Control "public"; }
    location ~* \.(css|js)$ { expires 30d; }
    gzip on;
    gzip_types text/css application/javascript image/svg+xml application/xml application/manifest+json;
}
```

## Поиск (SEO): что сделано в коде

- У каждой страницы свой `<title>` и `description` с городом, адресом и часами работы.
- `canonical` на каждой странице.
- JSON-LD Schema.org: рынок как `ShoppingCenter` (адрес, координаты, телефон, часы), сайт как `WebSite`, магазин одежды как `ClothingStore` внутри рынка, `CollectionPage` со списком категорий, хлебные крошки `BreadcrumbList`.
- Open Graph и картинка для превью ссылок `assets/img/og-image.jpg` (1200×630).
- `sitemap.xml`, `robots.txt`, 404 с `noindex`, иконки и `site.webmanifest`.
- Один H1 на странице, `alt` у картинок.

Ограничение: карточки товаров магазина собираются в браузере из массива `PRODUCTS` в `app.js`. В исходном HTML их нет, поисковик увидит их только после выполнения JavaScript.

## Скорость

- Фото пережаты: 7,16 МБ → 5,11 МБ на тех же размерах.
- Уменьшенные копии для телефонов через `srcset`: `assets/img/cat/sm/`, `hero-800.jpg`, `shop-hero-600.jpg`, `scheme-3d-900.jpg`, `logo-400.png`.
- Шрифты загружаются с самого сайта, основной файл кириллицы подгружается заранее (`preload`).
- Виджет Яндекс Карт (около 2 МБ) загружается, только когда до него остаётся полтора экрана прокрутки.
- Главное фото и основной блок страницы показываются без анимации прозрачности: иначе Chrome не засчитывал их как главное содержимое (LCP).

Замеры Lighthouse, мобильный профиль, локальный сервер:

| Страница | Скорость | Доступность | Практики | SEO | Вес |
|---|---|---|---|---|---|
| Главная | 66 → 77 | 92 → 96 | 79 → 100 | 100 → 100 | 5,3 МБ → 1,2 МБ |
| Категории | 75 → 87 | 90 → 95 | 100 → 100 | 92 → 100 | 1,3 МБ → 0,6 МБ |
| Магазин | 0 → 89 | 86 → 90 | 100 → 100 | 92 → 100 | 2,3 МБ → 2,2 МБ |

«Было» снято 10.10.2026 до оптимизации, «стало» 15.10.2026. Ноль у магазина был из-за того, что Chrome не находил на странице главное содержимое.

## Схема рынка

Картинка `assets/img/scheme-3d.jpg` (1672×941) и поверх неё SVG с тем же `viewBox`. Каждое здание описано многоугольником `<polygon>` в координатах картинки, поэтому контуры масштабируются вместе с ней. Наведение, фокус с клавиатуры и кнопки под схемой подсвечивают одно и то же здание. На устройствах без наведения контуры видны всегда.

Координаты сняты вручную по сетке. При замене картинки контуры нужно снимать заново.

## После запуска

Код только фундамент. В локальной выдаче («рынок Набережные Челны», «рынок Южный») решают карточки на картах и отзывы.

1. Яндекс Вебмастер: добавить сайт, подтвердить права (мета-тег `yandex-verification` уже подготовлен в коде, закомментирован), загрузить `sitemap.xml`, указать регион.
2. Яндекс Бизнес: заявить права на карточку «Агропромпарк Южный», указать сайт, часы, фото, отвечать на отзывы.
3. Google Search Console и Google Business Profile.
4. 2ГИС: указать адрес сайта в карточке.
5. Яндекс Метрика: счётчик перед `</head>` на всех страницах.
6. Название, адрес и телефон везде должны совпадать слово в слово.
7. Отзывы на Яндекс Картах и в 2ГИС (QR-код у входа).
8. Ссылки на сайт из ВКонтакте, канала MAX, городских справочников.
