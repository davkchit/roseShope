# Рынок «Южный» — сайт

Статический сайт: три страницы (`index.html`, `kategorii.html`, `magazin.html`) и страница `404.html`.
Сборка не нужна — файлы загружаются на хостинг как есть.

## Перед запуском — 3 обязательных шага

1. **Ссылка на MAX.** Откройте `assets/js/app.js` и в строке `const MAX_URL = 'https://max.ru/';`
   впишите ссылку на профиль или чат рынка.
   Где взять: MAX → Профиль → QR-код → «Скопировать ссылку» (вид `https://max.ru/u/xxxxxxxx`).
   Все кнопки «Написать в MAX» на сайте берут ссылку отсюда.
   MAX не умеет подставлять текст сообщения по ссылке (как WhatsApp), поэтому при нажатии
   текст («Хочу примерить: …») копируется в буфер и посетитель видит подсказку «вставьте в чат».
   Проверьте, что в настройках приватности MAX незнакомым людям разрешено писать вам.

2. **Домен.** Когда домен куплен, в папке сайта выполните:
   ```
   node tools/set-domain.js https://ваш-домен.ru
   ```
   Скрипт пропишет адрес в `canonical`, превью для соцсетей, микроразметке, `sitemap.xml` и `robots.txt`.
   Сейчас там стоит заглушка `https://example.com` — с ней сайт в поиск не пускать.
   Если домен поменяется — просто запустите команду ещё раз с новым адресом.

3. **SSL-сертификат.** В панели хостинга включите бесплатный сертификат Let's Encrypt **до** загрузки
   `.htaccess` — он перенаправляет все адреса на `https://` и на вариант без `www`.

## Что загружать на хостинг

Всё, кроме: `_parts/`, `tools/`, `README.md`, `.git/`.
(Если загрузятся — не страшно: они закрыты в `robots.txt` и `.htaccess`.)

В `assets/img/decor/` и `assets/img/store/*-new.jpg`, `jeans-straight-back.jpg`, `plan.jpg`
лежат картинки, которые сайт не использует (~3 МБ) — их можно не загружать.

### Если хостинг на nginx (VPS), а не Apache

```nginx
server {
    listen 80;
    server_name ваш-домен.ru www.ваш-домен.ru;
    return 301 https://ваш-домен.ru$request_uri;
}
server {
    listen 443 ssl http2;
    server_name www.ваш-домен.ru;
    # ssl_certificate ...;
    return 301 https://ваш-домен.ru$request_uri;
}
server {
    listen 443 ssl http2;
    server_name ваш-домен.ru;
    # ssl_certificate ...;
    root /var/www/yuzhny;
    index index.html;
    error_page 404 /404.html;
    location = /index.html { if ($request_uri ~ ^/index\.html) { return 301 /; } }
    location ~ ^/(_parts|tools)/ { return 404; }
    location ~* \.(jpg|png|svg|ico|woff2)$ { expires 180d; add_header Cache-Control "public"; }
    location ~* \.(css|js)$ { expires 30d; }
    gzip on;
    gzip_types text/css application/javascript image/svg+xml application/xml application/manifest+json;
}
```

## Что уже сделано для поиска (в коде)

- У каждой страницы свой `<title>` и `description` с запросами «рынок … Набережные Челны»,
  «агропромпарк Южный», адресом и часами работы.
- `canonical` — у каждой страницы один «главный» адрес, без дублей.
- Микроразметка Schema.org (JSON-LD): рынок как `ShoppingCenter` с адресом, координатами,
  телефоном и часами работы; магазин одежды как `ClothingStore` внутри рынка;
  хлебные крошки; список категорий. По ней Яндекс и Google понимают, что это за место.
- Превью ссылок в мессенджерах и соцсетях (Open Graph): картинка `assets/img/og-image.jpg`.
- `sitemap.xml`, `robots.txt`, страница 404 с `noindex`.
- Иконки сайта для вкладки, iPhone и Android, манифест.
- Скорость: фото пережаты (−2 МБ), шрифты лежат на сайте (а не на серверах Google),
  `.htaccess` включает сжатие и кэш.
- Один H1 на странице, подписи (`alt`) у всех картинок, тексты с названием города и адресом.

## Что сделать после запуска (без этого первого места не будет)

Код — это фундамент. В локальной выдаче («рынок Набережные Челны», «рынок Южный»)
решают карточки на картах и отзывы. Порядок действий:

1. **Яндекс Вебмастер** (webmaster.yandex.ru): добавить сайт, подтвердить права
   (код вставить в `<meta name="yandex-verification">` во всех трёх страницах),
   загрузить `sitemap.xml`, в «Региональности» указать Набережные Челны.
2. **Яндекс Бизнес** (business.yandex.ru): заявить права на карточку «Агропромпарк Южный»,
   указать сайт, часы, фото, категории, отвечать на отзывы. Это главный источник
   посетителей из Яндекс Карт и блока организаций в поиске.
3. **Google Search Console** + **Google Business Profile** — то же самое для Google.
4. **2ГИС**: в карточке фирмы указать адрес сайта.
5. **Яндекс Метрика**: создать счётчик и вставить код перед `</head>` на всех страницах —
   Яндекс учитывает поведение посетителей.
6. **Одинаковые данные везде.** Название, адрес и телефон на сайте, в Яндекс Бизнесе,
   2ГИС и Google должны совпадать слово в слово.
7. **Отзывы.** Просите покупателей оставлять отзывы на Яндекс Картах и в 2ГИС
   (можно QR-код на кассе / у входа).
8. **Ссылки на сайт** из группы ВКонтакте, канала MAX, карточек на картах, городских справочников.
9. **Обновления.** Раз в 1–2 недели добавляйте что-то новое: товары, фото, акции.
